# dependencies - OpenSteady Web

- Runtime: none. The extension ships only its own files.
- Dev: playwright 1.62.1 (package.json, exact pin). Node >= 20 (tested 22.22.0). Python 3 for tools/ and benchmark/analyze.py (stdlib only).
- Browser for suites: Playwright's Chromium, or CHROME_EXECUTABLE. 0.1.4 evidence used Chromium 141.0.7390.37 with Playwright 1.56.0.
