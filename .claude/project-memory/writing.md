# writing - OpenSteady Web

- Voice: plain, short sentences, second person for instructions, exact units ("0.5 seconds", "48 px").
- Every measured number names its conditions (scripted hand, shake RMS, trial count) and its file in results/.
- Always say what was not tested (Mac, Windows, Edge, people).
- Forbidden: "works for", "helps people with tremor", "clinically", "proven", "safe", "guarantee".
- Use "hold to click" (not "Hold-to-click"), "quick drag guard", "repeat guard", "near miss", "slip".
- UI strings live in extension/_locales/en/messages.json; [[Key]] renders as <kbd>.
