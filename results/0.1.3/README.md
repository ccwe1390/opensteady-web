# Results kept from 0.1.3

These files came with the 0.1.3 package. They were not regenerated for 0.1.4 and they describe 0.1.3. According to that build's own validation document they were produced with Node 24, Playwright 1.62.1 and the Chrome for Testing headless shell, version 151. Only the Chrome version is recorded inside the files themselves.

| File | What it is |
|---|---|
| `browser-controller.json`, `browser-controller-console.txt` | The 27 controller only browser checks of 0.1.3. The first lines of the console file say `opensteady-web@0.1.2`. That is how the file arrived with 0.1.3. |
| `review-native-link-drag.txt` | Native link and button dragging with no extension |
| `review-policy-variants.txt` | The 0.1.3 benchmark under relaxed press rules, in percentages |
| `review-press-limit.json` | How many presses that needed help exceeded the 12 px limit at 8 px of shake |

The 0.1.4 equivalents are one folder up.
