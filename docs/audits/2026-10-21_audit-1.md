# Audit 1 - OpenSteady Web 0.1.5

Date: 2026-10-21. Auditor: Claude (Claude Code session), at Carol Chen's request. This is the first dated audit in `docs/audits/`. The 0.1.4 independent reviews are recorded in `docs/REVIEW-RESPONSE.md`.

## Scope

- **In full:** everything changed in 0.1.5 (keyboard shortcuts, outline style, message catalog, UI pages, CSS, tests, tooling, CI, documents).
- **Spot checks of 0.1.4 code:** the trust boundary in `background.js` and `content.js` messaging, every rule constant named in the documents against the code, and the risky-label heuristic in `targets.js`.
- **Not re-audited:** the gesture policy, selector, shake meter and quick drag guard logic. They are unchanged since 0.1.4, which had three independent review rounds, and the 61-fault check still catches every fault (`results/mutation-check.txt`).

## Method

I read the code, ran the unit, package, fault, browser and probe suites (results in `results/`), measured contrast with `tools/contrast.py`, and probed the risky-label expression with a list of common labels. Every finding below is tied to a line and was confirmed by running something. None is only "plausible". Carol asked for every finding to be fixed. All are fixed except A1-8, which is a note.

## Trust boundary (spot check)

- `background.js` rejects a foreign `sender.id`, allows control messages only from `chrome-extension://<id>/ui/`, and allows content scripts only `content-config` from frame 0. The mocked tests cover all three.
- The keyboard shortcuts are not messages. They reach `runCommand` only through `chrome.commands.onCommand`, which pages cannot trigger. Unknown command names are ignored (test "unknown shortcut names are ignored").
- `ui/i18n.js` writes text nodes only. A message containing `<b>` is shown as text (test "the i18n helper renders [[Key]] as kbd without parsing HTML").
- The `outline` setting is allowlisted to three names. A crafted value cannot reach `style` (test "outline style is appearance only").

## What was not checked

The policy, selector, shake meter and drag guard in depth. Real permission prompts. Behavior after a browser restart. Mac, Windows and Edge. Any real website. Any person.
