OpenSteady Web

Version 0.1.0 · Early release for Chrome and Edge desktop.

Assistance

Near misses need a visible outline first. Correct clicks pass through. Hold Alt to bypass. Press Escape to pause a page, then use the toolbar to resume.

Sites you enabled

    Use the toolbar on a site to turn it off and revoke its permission. A remembered site includes all ports on the same scheme and hostname. Temporary tab choices last until the browser closes.

    Privacy

    No accounts, analytics, advertising, network requests, or remote code. Settings and chosen site names are saved locally. Page contents, pointer paths, and what you type are never stored by the extension. Diagnostic counts stay in memory until the page reloads.

    On enabled pages, OpenSteady reads control geometry and short labels to decide whether assistance is appropriate. Trace recording is available only in the separate local lab, with explicit start and export buttons.

    Where assistance stops

    Top-level http and https webpages only. Browser tabs, the address bar, PDFs in the browser viewer, desktop apps, iframes, closed shadow roots, touch, and drag assistance are outside this release.

    Forms, payments, destructive controls, text editing, file pickers, and unlabeled controls receive ordinary clicks. Risk detection is conservative and imperfect; this is not a guarantee against accidental actions. Some sites require trusted native input or react before the click, so redirected clicks may not work there. Turn assistance off for those sites.

    This is an experimental accessibility tool. Benefit for people with tremor has not been established.
